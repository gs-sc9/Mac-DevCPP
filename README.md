# Mac‑DevCPP

A recreation of Dev‑C++, C/C++ IDE for macOS
✨ Features

- MinGW compilation toolchain
- fast.dmg high‑speed compilation mode
- Quick Search
- Simple local‑network AirDrop‑like file transfer

📦 Download & Installation
Head to [Releases](https://github.com/gs-sc9/Mac-DevCPP/releases) to download `Mac‑DevCPP.app.zip`
Extract the archive to get the app.

⚠️ Important Notice
This app bundle is unsigned.

1. After extracting, right‑click the app and select **Open**; do not double‑click directly.
2. Grant Full Disk Access permission in System Settings.
3. Supports macOS 13+
