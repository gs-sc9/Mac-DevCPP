# Mac‑DevCPP

A recreation of Dev‑C++, C/C++ IDE for macOS

## ✨ Features

- MinGW compilation toolchain
- fast.dmg high‑speed compilation mode
- Quick Search
- Simple local‑network AirDrop‑like file transfer

## 📦 Download & Installation

Go to [Releases](../../releases) to download `Mac‑DevCPP‑v1.0.0.pkg`

## ⚠️ Important Notice

This installer package is unsigned.

1. After installing the pkg, **right‑click the app and select Open; do not double‑click directly**
2. Grant **Full Disk Access** permission in System Settings
3. Supports macOS 13+
